macOS first launch

This app is not Apple-notarized yet, so macOS may show a security warning the first time it is opened.

  1. Move SST Composite Optimizer.app to the Applications folder.
  2. Try opening the app once. If macOS blocks it, choose Done.
  3. Open System Settings > Privacy & Security.
  4. Find the blocked app message and choose Open Anyway / Yine de Aç.
  5. Open the app again and confirm Open / Aç.
